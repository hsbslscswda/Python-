# Gemini v0.2.0 审查处理与 v0.3.0 证据

审查基线：ac1e4ba9b842d915dc05b10e9563a1f5aa33198f。Gemini没有运行Windows、EXE或新动作测试，其“实测复现/100%交叉印证/所有现象精确根因/一次根治”不作为证据。本机新找到的3725帧、约249.5秒日志才是独立运行证据：A五次增强事件但OVERDRIVE只有七个快照，B五次蓄势、无出刃，C十三次展开、一次折镜、无碎镜。没有动作标签，不能据日志统计推定每次具体意图或成功率。

| 建议 | 判断与实际修改 |
|---|---|
| 不可靠Pose腕的低常数代价会抢走单Hand | 已构造复现并修复。无可靠Pose/近期历史时匹配代价高于不分配；有历史时按几何关联。新增单手/标签翻转/鬼影负例 |
| ambiguous不应把可辨认的一手连坐清空 | 接受并限制。逐侧保留唯一一致匹配或鲜明近期连续性；真正重合仍不猜身份，不无条件锁住任一检测框 |
| 无Hand时提高腕/肘门槛 | 接受，Pose腕0.50、肘0.40；弱鬼影不画成强黄线，Pose回退用细虚线。分类分数仍只用于身份弱证据 |
| 正面真实肘角永远115–125度、默认改68/122 | 不采用。报告未实测，日志也无动作标签；单目深度有风险但不是固定角度定律。不用掌宽或2D位移冒充伸直。个人校准保留样本量要求，按噪声检验允许稳定的较小区间，并显示保存状态 |
| 中值7帧必有450ms延迟、改3帧/静止深度保持0.8s | 部分接受。原窗按0.32秒裁剪，非固定450ms。直接三点快滤波曾让现有抖动测试失败，未交付该方案；改为连续同向角变化后短时加快，默认保持0.35秒后有界缓降，不据2D静止无限锁强度 |
| near无条件进TRANSFER并豁免intent超时 | 不采用无条件方案。保留实际观察/靠近轨迹，使用有界位移与距离变化容许慢靠近；扩展腕旁候选、增加脱离去抖；确认期迁移到45%。施法手短遮挡宽限有限，握拳/放下仍优先，长期丢失仍停止 |
| Blade只要tracked就续轨迹、取峰值、降低全部阈值 | 调整。最多0.20秒、可靠Pose腕、与已有Hand锚对齐的衔接；Pose自身不能发攻击，Hand重获须一致。比较相邻速度与拟合速度，保留跨度/直线度/跳点/冷却约束，未盲目降所有阈值 |
| Mirror用任意tracked（包括未观察到的手）唤醒 | 调整。需真实观测的双掌，允许侧掌OTHER，FIST/UNKNOWN不能直接唤醒。已观察过的手可短暂Pose维持几何，但不能据此碎镜 |
| 缩镜d<0.38单帧立即关闭 | 已构造复现并修复。极近、低速保持0.30秒才关闭；缩小后可再拉开。测试明确包含小镜重开、慢合/快合分离 |
| 解除±34°旋转、支持连续角度 | 已构造复现并修复。连续无向轴解缠绕，不简单删除取模，避免标签翻转产生180°跳转；转动保持增加折镜入口 |
| 0.35秒内峰值+下一帧丢手直接碎镜 | 拒绝丢手触发。只使用持续可见的收缩观测，短期峰值在扩张或丢手时清除；需要当前双手可见，禁止重获跳点形成速度 |
| Shader/guide/STYLE无需修改即可100%兼容 | 只作候选，适配后采用。修正逆序smoothstep、过曝、非单位倾斜轴；身体朝向取可靠Pose世界肩线，不从屏幕平移伪造Yaw；保留矩形镜面与碎片一致，镜内折镜纹理冻结也复用同一映射。新增uniform已同步绑定 |
| 连续示范小人 | 采用并修正。青色示范/黄色追踪分开；跨阶段插值，挥刃/快合的示范时间匹配实际规则。没有沿用“突破150%”“任意合掌/丢手碎镜/零延迟”等不成立文案 |

关于smoothstep逆序边界，依据[Khronos GLSL规范](https://registry.khronos.org/OpenGL/specs/gl/GLSLangSpec.4.60.pdf)：edge0>=edge1结果未定义。关于Pose输出，依据[Google文档](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker?tab=Python)：存在图像与世界坐标输出；它不提供本审查所称的普遍120°精度上限。

## 下一轮最多三个问题

1. 单手/弱Pose/角色交叉时，逐侧关联及0.20秒Pose衔接是否还有身份跳转或凭Pose误斩的路径？给具体时间序列。
2. 慢搭臂、提前视觉迁移、有限遮挡宽限、按噪声筛选的个人校准，是否仍存在增强无限保持或“稳定但迟钝”？区分构造角度基准与真人深度。
3. 镜面极近保持收镜、连续旋转、可见快合/丢手/重获，以及CPU冻结折镜纹理与GL镜内图像映射是否一致？给最小复现，不建议缺手外推触发。
