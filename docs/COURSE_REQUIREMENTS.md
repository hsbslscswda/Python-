# 介绍

Python 大量优秀的第三方库，为其构建强大的应用和开展研究提供了无限可能。当下，基于计算机视觉、语音和自然语言处理三大方向的人工智能技术，已成为构建工程应用的基础。在此背景下，为了让同学们基于实践更好地掌握Python知识，同时也为了锻炼大家的创新能力、工程开发能力和团队合作精神，培养科研兴趣并为进一步的深造打下基础，故安排此次综合课程设计。

MediaPipe 是一款由 Google Research 开发并开源的多媒体机器学习模型应用框架，可用于处理视频、音频等时间序列数据。该跨平台框架适用于桌面/服务器、Android、iOS和嵌入式设备，如Raspberry Pi和Jetson Nano。与资源消耗型的机器学习框架不同，MediaPipe只需要极少的资源，甚至嵌入式物联网设备都可以运行它。

## 应用型项目要求

应用型项目的最终目标，是构建一个使用Mediapipe的完整、易用的应用系统。

### 交互/前端

编程语言不限，形式可以是控制台、App、小程序、Web系统或者客户端等。项目务必要考虑应用的目标用户和定位，比如能否方便调用摄像头，面向的人群是否可以轻松操作等等。

- 前端可以在本地（开发环境）演示，也可以上线。不会影响评分。

### 后端

要求基于Python实现。后端可以部署在本地，也可以部署到服务器（不影响评分）。如果是前后端分离架构可以使用Flask，Django等。

### 用户体验

综合课设对于用户体验的要求较高，即使是使用控制台也必须要有完善的细节，例如用户可以方便打开应用，有良好的指引等。完善的用户体验不一定非要有用户登录这些内容，功能是根据目标用户需求设定的。

## 研究型项目要求

除了应用类型外，还可以进行研究型的项目。研究型课程设计，可以不做出完整的应用，但需要有较创新的idea、综合的文献分析、良好的实验结果或其它有说服力的阐述内容。另外，研究的细节也需要完整阐述，例如使用深度学习模型的数据处理过程，调参细节等。
