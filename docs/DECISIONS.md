# 当前技术决策（v0.3.0）

保留Python主体、容量一采集与快照、同帧VIDEO Hands/Pose、独立有序事件、Qt主线程OpenGL及当前Qt FBO，保持现有任务分支。旧版见Git标签v0.2.0，不另起工程。

- 可靠性优先于迎合模拟指标。不能把掌大小、2D腕静止、躯干屏幕平移当作深度/完全伸直/Yaw；世界坐标只在各自模型内使用。Hand分类分数不是定位置信度。
- 单手关联修复低代价抢配与整组歧义清空。姿态回退有质量门槛、近期锚与时限，诊断区分实测Hand和Pose估计。真正不可辨认时停止，不强行猜左右。
- 施法角色在会话内锁定。支持手自由、握拳停法留阵、放下收阵；慢靠近可增强，但必须有靠近历史和近期观察。确认期部分迁移提供反馈，释放/丢失去抖不能屏蔽明确停止。
- 个人弯伸校准不能被固定122度替代。样本足量、噪声小于有效区间才保存；动态控制加速需要连续证据，缺深度仍保持后缓降。
- Blade允许短时观测Pose续轨迹，但绝不由Pose-only发斩；重获与原轨迹不一致则丢弃。Mirror丢手不会碎镜，峰值不能跨丢失或扩张借用。缩镜关闭需要保持，镜面角度解缠绕避免身份翻转突跳。
- GPU视觉在用户提供的候选上适配。Pose肩线估计用于有界平面倾斜，2D施法方向只作为艺术表现；仍为2.5D且无精确人体深度。正常阵保留透明中央通道、脸部近似避让，极限保持多层/冠冕/冲击环。
- 碎片使用有界的镜内映射冻结纹理，不重新采样后续视频；QPainter也复用该图像映射。只缓存一个当前镜面patch与一个碎镜事件，不无限累积。
- 缺模型先校验再导入native，采集等待模型成功。维持v0.2.0的中文buffer加载修复，不改回路径模式。关闭异步等待线程，分别记录采集/推理耗时，不能保证所有驱动1.5秒。
- Gemini静态报告与真人日志分开。六项新构造复现先失败再修复；实际动作与审美仍需本人复测，默认阈值仍为待调初值。没有完成D或虚构课程报告/参与者。

- 退出阶段以进程返回码为准，不能仅看shutdown日志。声音对象在Qt循环仍运行时清源/DeferredDelete，窗口关闭即删除，再退出QApplication；Qt错误消息也写日志。旧0xC0000409没有原生调用栈，未作唯一归因。

## v0.3.1 用户指定升级

按本轮明确授权覆盖八文件、使用黑曜石鎏金风格并在下拉框隐藏月刃（保留内部index 1）；不回退默认134°、28%放大及d<0.72/峰值速度>1.35的碎镜调优。包内130/134/148与流水线原160默认不一致，已统一134；已有个人校准仍优先。默认区间缩短会放大同一角度误差，因原抗抖用例失败，稳态时间常数由包内0.19调至0.24秒，快速路径保留0.050秒，未放宽抖动断言。

过载阶段可在当前可靠Pose持续确认施法臂抬起时维持意图；支撑腕丢失、整体姿态失效、显式握拳或放下仍停止/退出。镜界延长的是已观察双手的有界姿态维持，不允许丢手产生碎镜事件。参数是用户要求的实测候选，不是通用人体标定或“彻底无抖”的证明。

## v0.3.2 雕纹花窗集成

第二份包按用户授权覆盖，随后保留上一轮control的134°与稳态0.24秒。界面和guide新FiligreePanel原样保留；着色器保留七组花窗/星盘结构和36格程序化铭文，修正区域遮罩应乘在线强度而非距离上，并修正分隔带的距离方向和逆序smoothstep。

新镜内纹样改变，冻结碎片与QPainter复用的CPU映射也必须同步。通过tools/shader_probe.py使用实际Qt/ModernGL离屏上下文比较固定画面的过白比例，并对四组折镜/角度组合核对CPU/GL镜内像素。图形缩放改为依次等待完成，再开始动作回放，防止首次shader编译把多个检查挤到同一尺寸。不放宽色标、长丢失或退出保护。

## v0.4.0 娱乐交互与持续状态

手动切换仅保留短防抖，不用看见垂下的双手；删除任意控件点击冻结输入0.65秒的行为。长输入间隔清除A搭臂历史，保留会话；月刃仍清轨防跳点攻击。镜面以确认收镜/碎镜为退出，丢手保持；当前Pose肩肘可带动最近腕偏移，标注为估计，不能产生碎镜速度。

Water/Fire是纯Python状态机，与同帧不可变EffectObject快照绑定。水球世界坐标来自假定焦距和人体/掌尺度的逆投影，半隐式小步弹簧与重力，人物/镜头用扫掠碰撞避免低Hz穿透。最多8个弹体/8个飞溅，画面最多12个对象。人物碰撞启用num_poses=2，按肩部连续性选择控制人，另一人作为粗碰撞体；没做人脸身份或真实深度。火焰按手锁定解锁/保持/熄灭，新鲜度与时间间隔参与确认，长期缺失缓熄，不根据缺失推定拳。

GLSL暖金属阵直接做材质合成，释放物冷蓝/紫色且沿方向运动；Bloom默认大幅降低。水球折射/高光/水滴与火焰噪声舌焰为程序化视觉，不声称SPH/Navier-Stokes流体仿真。QPainter复用同一识别/物理状态，画质较简化。

手部独立时明确标注HAND_ONLY，诊断层只画真实手点，不从缺失的零肩肘坐标画假肢体。火焰构造演示使用无身体关键点输入。
