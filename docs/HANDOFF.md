# v0.3.0 修复版交接

固定代码以审查包 BASELINE.json 为准，分支 codex/mirror-moon；保留用户仓库与旧版本。新版真人动作尚未复验，不把构造测试当作通过。

## 最简单的打开方式

本机双击 outputs 中「双击启动镜中取月.lnk」。窗口须显示 v0.3.0，默认开启实际追踪黄线与右侧火柴人示范。队友下载 GitHub Releases 的 MirrorMoon-Windows-v0.3.0.zip，完整解压，双击「启动摄像头.cmd」。只复制 EXE 无法运行。

关闭摄像头：点按钮或按 C，指示灯应熄灭；窗口仍保留。再次点「打开摄像头」恢复。Esc 收招，空格暂停，F11 全屏。

## 三分钟复测

1. 点「记录 G0 日志」。可先选「校准右臂」做20秒校准，再选左臂单独校准。保持舒适弯曲与朝前伸直，不必锁死肘关节。样本不足不覆盖原值。
2. 星环：胸前/肩前一手松握拳 → 另一手开掌抬起 → 朝前弯伸三次 → 召唤手离开胸前自由活动 → 搭到施法前臂中段稍停 → 观察是否超过100%且阵移至掌前 → 放开恢复普通 → 施法手握拳停法留阵 → 放下施法手收阵。轻微侧身与左右换手各试一次。
3. 月刃：手收到另一侧肩前，停一秒（不应反复失败）→ 向外横挥/斜挥。仅蓄势不算释放，应看到月刃并提示“已释放”。再反向挥一次。普通招手、整理头发和身体平移不应出刃。
4. 镜界：双手开掌靠近稍停 → 向两边拉开，应有实时画面镜面；转过90°应连续，转过约30°稍停可折镜。先缩小再拉开（不应立即关闭），再慢合并保持约0.3秒关闭；重开后快合到一拳距离，不必拍掌，应有带冻结画面的碎片。只丢一只手不能碎镜。
5. 再点「停止记录日志」，点「打开日志文件夹」直接找到 JSONL，位置也显示在窗口。关闭摄像头，确认指示灯熄灭。反馈系统、失败步骤和大致时间点即可。

日志位置：%LOCALAPPDATA%\MirrorMoon\diagnostics。旧两份日志已找到用于定位，不随 GitHub/Gemini 审查包公开。
