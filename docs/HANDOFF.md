# 当前交接与真人自测

2026-11-07，v0.1.0。精确代码标识以审查包 `BASELINE.json` 的 commit 为准；分支 `codex/mirror-moon`。基于用户目标仓库原始提交 `79cddf2`，没有另建无关仓库，没有推送远端。

## 最短自测（约 3 分钟）

1. 解压运行包，保留完整文件夹，双击 `MirrorMoon.exe`。选择摄像头，点「打开预览」。先让双肩、双肘和双手清楚入画，保持正常光照。
2. 勾选「诊断」，点「记录 G0 日志」。不录图像，只记录关键点、状态和时序。可选 20 秒校准；当前使用右臂端点，左右臂共用。然后点「开始施法」，先自然放下双手半秒。
3. 星环术：胸前握拳→另一手开掌→朝镜头舒适弯伸三次→施法手握拳。反馈强度是否连续可逆、停法后法阵是否仍在。再开掌施法，召唤手移去握住前臂中段→保持→回胸→再次移去并放开。记录失败发生在哪一步，左右手都试一次。
4. 月刃术：切换系统后先放松双手。手收至对侧肩前停留，再做舒适的向外横/斜挥；短暂停顿后反向挥。接着只做普通招手、整理头发、横移身体，观察是否误触。无需猛甩。
5. 镜界术：双手靠近开掌停留，拉开；移动、改变距离/高差；拉大保持后一起平移；先慢合关闭，重新准备后快合一次。另做“只让一只手出画”，不应碎裂。
6. 点「停止记录日志」，关闭窗口，确认摄像头指示灯熄灭。日志在 `%LOCALAPPDATA%/MirrorMoon/diagnostics`；截图须自己主动点「截图」。可以只回传关键点 JSONL 和具体失败步骤；个人录像由用户决定是否提供，不自动公开。

如果根本没有预览：换摄像头序号、关闭其它占用摄像头的软件；若模型缺失按界面说明准备模型。图形不可用时用随包的「兼容画质.cmd」；回放入口明确显示为视频回放。

- 主动关键点诊断、可注入时间的纯 Python 规则、JSONL 回放、自动化测试与可复现图形/包体检查。
