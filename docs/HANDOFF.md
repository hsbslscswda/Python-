# v0.4.0 最短自测

双击outputs的「双击启动镜中取月.lnk」，标题必须是v0.4.0。队友下载MirrorMoon-Windows-v0.4.0.zip，完整解压，双击「启动摄像头.cmd」。兼容画质用同目录CMD。

1. 坐稳，点「记录日志」。星环/镜面让肩肘尽量入画；水球/火焰只需手。无需先垂手即可手动切换。
2. 星环：横臂放在颈前或胸前，另一手开掌。查看暖色法阵、蓝色或紫色向外发射的射流。搭臂过载，握拳停法，放下收阵。无需锁死肘角。
3. 镜界：双手靠近稍停再拉开，控制大小/位置/旋转。试一只手或镜面画外、遮住手，再回来；应保持。慢合停住关闭，快合碎裂。
4. 水球：握拳后摊开，转动手腕应都能召唤，慢移/急停看惯性。双掌相对夹球再拉大；把另一手搭到施法腕或前臂发射。朝镜头发射看飞溅；用两个人测试人物碰撞。拍掌结束，单纯丢手不应结束。暂停保留；手动切换/重置/关摄像头会清理。
5. 火焰：先张开→握拳持续2秒→再张开。左右手分别试，再同时试。半握火焰收缩、全握或翻掌向下熄灭、张开重燃。暂时遮手不应立刻熄灭。
6. 点停止记录和「打开日志文件夹」，默认%LOCALAPPDATA%\MirrorMoon\diagnostics。C关闭摄像头；确认灯熄灭。反馈法术、失败步骤、大致时间。不要把敏感录像发到公共仓库。

本版水球是有透视、弹簧惯性、重力与扫掠碰撞的视觉模拟，不是完整流体求解。掌前约5cm依赖假定手宽/肩宽和相机焦距，无法由单目证明精确厘米；人物碰撞用第二个Pose的估计空间，不是精确深度。多人的交叉身份、手掌正反与人体遮挡仍待真人复验。构造回放和摄像头连通均不等于真实体验通过。
