## 发现并修复的问题

- Qt 6.12 音效 Infinite 枚举需整数值；已按实际 API 修正。
- 握臂接近判定原来使用每帧距离差，27Hz/30Hz 表现不同；改为单调时间短窗速度，新增多采样率回归。
- 双腕重叠时类别标签可能“解开”几何歧义；改为 UNKNOWN，并增加回归。
- 固定等待后直接关闭可能留下正在释放的原生模型；改为请求停止后在事件循环中等待实际线程退出。
- 全局 Anaconda 同名 ICU DLL 混入 EXE；构建隔离 PATH 修正，未修改系统 DLL。
- 曾错误排除 MediaPipe 顶层需要的 Matplotlib；最终包保留它。包体测试增加“无 pipeline_error 且有模型快照”的断言，防止把退出码 0 当作摄像头链路成功。
